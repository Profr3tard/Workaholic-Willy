# Workaholic-Willy, the complete install.
#
#   pip install -r requirements.txt        NVIDIA GPU, the supported path
#   pip install -r requirements-cpu.txt    a host that cannot take the CUDA wheels
#
# These two files are the whole dependency set. There are no optional extras:
# a package that is only installed "if you need it" is one whose absence is
# discovered on the day it is needed. They differ only in the PyTorch block
# below, and every version is pinned exactly so an install is reproducible.
#
# The CUDA wheels import fine on a machine with no GPU; torch simply reports
# cuda.is_available() == False. That is why this file, not the CPU one, is what
# CI installs: the runner then resolves the same dependency set the workstation
# ships.

# ---------------------------------------------------------------------------
# PyTorch, CUDA 12.8
#
# The +cu128 local version is load-bearing. --extra-index-url adds an index
# rather than replacing one, so a plain torch==2.7.1 is equally satisfiable
# from PyPI, where it is the CPU build, and the resolver is free to pick
# either. Naming the local version makes the CPU wheel a non-match.
#
# --index-url would also fix that and would be wrong: it replaces the default
# index, and pydantic, numpy and opencv are not on the PyTorch one.
#
# The RTX 5080 is Blackwell (compute capability sm_120) and requires CUDA 12.8
# or newer. The cu128 wheels carry sm_120 kernels; cu121 does not.
#
# torchvision 0.22.1 is the release that pairs with torch 2.7.1.
# ---------------------------------------------------------------------------
--extra-index-url https://download.pytorch.org/whl/cu128
torch==2.7.1+cu128
torchvision==0.22.1+cu128
